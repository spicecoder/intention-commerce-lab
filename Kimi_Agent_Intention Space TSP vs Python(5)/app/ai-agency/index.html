BOUNDED GENERATIVE PARTICIPATION

AI acts as a DN, not as the controller.

An LLM can interpret and generate within one declared participation. Admission, authority, routing, and consequential human decisions remain outside the model.

Public boundary: this page explains the implemented DN_LLM pattern. No remote model is called from this static site.

THE PARTICIPATION BOUNDARY

Generated text remains a candidate.

01 / DECLARED INPUTS_LLMRequest

The Signal tells the model why it is participating and supplies only declared observation Pulses.

02 / MODELDN_LLM

A configured local or remote provider returns an untrusted intermediate response.

03 / CANDIDATEcandidate Signal

Unexpected identities, Pulses, Trivalence, or Response shapes are not admitted.

04 / VALIDATED OUTPUTS_LLMResponse

Deterministic checks decide whether the candidate may enter the continuing application path.

FOUR CONTROL QUESTIONS

Fluency answers none of them by itself.

Purpose

Is the Intention explicit, and were only the declared observations supplied to the model?

Authority

Can the participation acquire undeclared tools, select its own next CPUX, or route itself? It must not.

Validation

Is provider output still only a candidate until Signal identity, Pulse set, Trivalence, Response shape, and context checks pass?

Human control

Does a consequential act still require its declared Taskpoint and App-absorb Signal, rather than conversational wording?

PROVENANCE / CREDENTIALS

Record the provider without exposing the secret.

Model identity, provider identity, bounded context references, raw candidate output, guardrail findings, and admission result belong in the agent trace. Credentials remain outside Signals and application manifests.

A deterministic mock provider can validate mechanics without a network or credential. A real remote provider additionally requires an authenticated endpoint, privacy controls, rate limits, and an explicit deployment boundary.

Honest limit: contract validation can reject malformed or unauthorized output. It cannot prove that a well-formed statement is true or that its intended meaning is correct.
